فقط Composite 

چرا این روش را انتخاب کردم؟ اگر به‌جای آن top/margin/height را انیمیت می‌کردم، Layout (Reflow) برای کل صفحه دوباره اجرا می‌شد. اگر box-shadow را مستقیم انیمیت می‌کردم، هر فریم Paint دوباره انجام می‌شد. با این روش هیچ عنصر دیگری جابه‌جا نمی‌شود و فقط لایه GPU حرکت می‌کند. برای بررسی: در DevTools، پنل Rendering، گزینه Paint flashing را روشن و پنل Performance را ضبط کرده .در هنگام hover فقط Composite دیده می‌شود. در حالت «کاهش حرکت» سیستم‌عامل (prefers-reduced-motion: reduce) همه انیمیشن‌ها و اسکرول نرم حذف می‌شوند. 

۳. پنهان کردن منو 

منوی دسته‌ها با visibility: hidden به‌همراه opacity: 0 پنهان می‌شود. visibility: hidden عنصر را هم از دید و هم از ترتیب Tab و صفحه‌خوان حذف می‌کند، ولی با transition-delay می‌شود انیمیشن بسته شدن را هم نگه داشت. روش‌های دیگر را کنار گذاشتم: opacity: 0 تنها، لینک‌ها را همچنان فوکوس‌پذیر نگه می‌دارد؛ display: none هم قابل انیمیت نیست. منوی موبایل با یک <input type="checkbox"> واقعی و انتخابگر :has(:checked) باز و بسته می‌شود؛ بنابراین با کیبورد (Space) هم کار می‌کند. 

۴. URL Fragment 

وقتی کاربر روی لینک #dairy کلیک می‌کند، فقط مرورگر در همان صفحه به عنصر با id="dairy" اسکرول می‌کند. با scroll-margin-block-start عنوان بخش زیر Header نمی‌رود، و با :target عبارت «اینجا هستید» نشان داده می‌شود. 

۵. کاروسل بدون JavaScript 

کاروسل یک <ul> با display: flex داخل یک عنصر با overflow-x: auto و scroll-snap-type: x mandatory است. لمس، ماوس (چرخ و کشیدن اسکرول‌بار) و کیبورد (کانتینر tabindex="0" دارد و با فلش‌ها اسکرول می‌شود) کار می‌کنند. دکمه‌های ابتدا/انتها لینک‌هایی به id اولین و آخرین کارت هستند؛ پس مرورگر به آن کارت اسکرول می‌کند و آدرس صفحه هم تغییر می‌کند. چون جهت صفحه RTL است، اولین کارت سمت راست قرار می‌گیرد. 

۶. دسترس‌پذیری 

    بررسی‌ها: کار با کیبورد (Tab از لینک «پرش به محتوای اصلی» شروع می‌شود)، حلقه فوکوس ۳ پیکسلی، کنتراست متن حداقل ۴٫۵ به ۱، فقط یک h1 با ترتیب درست عنوان‌ها، Landmarkها (header، nav، main، footer)، و اندازه ناحیه لمس حداقل ۴۴ پیکسل. 

    آیکون‌ها و ایموجی‌های تزئینی aria-hidden دارند؛ دکمه‌های بدون متن (+ ، سبد، منو) aria-label دارند. 

    ابزارها: DevTools (پنل Accessibility و ابزار کنتراست)، Tab زدن دستی، اسکریپت Playwright برای بررسی اسکرول افقی از ۳۲۰ تا ۱۹۲۰ پیکسل، و بررسی ساختار HTML (تکراری نبودن id، سالم بودن لینک‌های #). 

۷. لوگو 

لوگو از شکل‌های پایه SVG ساخته شده (مربع گرد، ذوزنقه، دو مسیر ساده و یک برگ) و مستقیم داخل HTML نوشته شده است. SVG را انتخاب شده است چون در هر اندازه تیز می‌ماند، حجمش چند صد بایت است، بدون درخواست شبکه‌ای جدا بارگذاری می‌شود، و برخلاف PNG نیازی به نسخه‌های مختلف برای صفحه‌های با تراکم بالا ندارد. لینکِ لوگو aria-label="سوپرمارکت باز-بسته، رفتن به بالای صفحه" دارد.
