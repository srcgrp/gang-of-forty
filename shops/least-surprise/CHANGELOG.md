# Changelog

## [1.0.0] - 2026-11-27

- Home page with banners, categories and product carousels.
- Product listing with search, sorting and category navigation.

- Responsive Persian RTL interface with light and dark themes.
- Docker configuration and GitHub Actions CI/CD workflow.

- Organized application into API, cart, catalog, checkout, components, hooks and storage modules.
- Prepared production and preview deployments on Vercel.
