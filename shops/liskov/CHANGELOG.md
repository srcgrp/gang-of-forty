# Changelog

All notable changes to Liskov Shop are documented here.

## [1.0.0] - 2026-11-27

### Added

- Persian RTL grocery storefront built with React and TypeScript.

- Homepage with promotional banners, product carousels, and categories.

- Product search and category filtering.

- Product listing pages with URL-based price sorting.

- Product detail pages.

- Shopping cart with quantity controls and persistent storage.

- Light and dark theme support.

- Validated checkout form and order summary.

- Loading, empty, and error states for catalog data.

- Responsive mobile layout.

### Deployment and Infrastructure

- Multi-stage Docker build using Node.js and Nginx.

- Nginx configuration with SPA fallback and API proxy.

- Vercel deployment with API rewrite configuration.

- GitHub Actions workflow for CI, Docker builds, and Vercel deployment.

- Automated checks using Oxlint and TypeScript.

- Mobile viewport verification and screenshot documentation.

### Documentation

- Added AGENTS.md and CLAUDE.md coding instructions.

- Added release workflow skill for Claude.

- Added project architecture documentation.

- Added setup, development, and deployment instructions.
