# Changelog

## [1.0.0] - 2026-11-25

Online supermarket.

### Added

- Bootcamp online grocery storefront
- Header, announcement, menu, categories, banners, footer, and product page
- Carousels, sale countdown, and GSAP animations
- Dynamic catalog, cart, and checkout
- Vite, TypeScript, Zustand, and npm scripts
- Theme names, oxlint, and AGENTS.md
- Dockerfile, deploy pipeline, README, Vercel config, and live URL

### Changed

- HTML and CSS structure, including folder layout
- JavaScript rewritten in TypeScript
- Catalog, cart, checkout, and home components refactored
- Category pick logic and stock handling
- Count-up animation switched to GSAP

### Fixed

- HTML validation errors
- Typecheck and import extensions
- English phone digits shown as Persian
- RTL text and styles
- Error messages, preview script, and Dockerfile
- Removed committed `.env`
