# طراحی سوپرمارکت بوی کد

## ۱. نیازمندی‌ ها
- کاربر بتواند محصولات، قیمت، تخفیف و وضعیت موجودی را ببیند.
- با انتخاب دسته، محصولات همان دسته نمایش داده شوند.
- کالای موجود به سبد اضافه شود و تعداد سبد بعد از Refresh باقی بماند.

## ۲. بخش‌ های صفحه
- نوار اطلاع‌رسانی، هدر، منوی اصلی و منوی دسته‌ها.
- بنر اصلی، دسته‌بندی کالاها و بنرهای پیشنهاد ویژه.
- کاروسل‌ های محصولات و نمایش محصولات دسته ی انتخاب‌ شده.
- شمارنده ی سبد خرید، راهنمای خرید، پرسش‌ های پرتکرار و فوتر.
- افکت تایپ نوار اطلاع‌ رسانی و آتش‌ بازی دکمه ی دریافت کد تخفیف.

## ۳. داده‌ها و صاحبشان 
- سرور رابط  : (API)محصولات، قیمت ‌ها، موجودی، تخفیف‌ ها، دسته ‌بندی‌ ها و محتوا.
- وضعیت (State) برنامه : نگهداری و مدیریت داده ‌های دریافت‌ شده، وضعیت بارگذاری و وضعیت فعلی سبد خرید.
- حافظه مرورگر : (localStorage)  ذخیره‌ سازی سبد خرید در مرورگر برای حفظ اطلاعات آن پس از بارگذاری مجدد صفحه.
- لینک (URL): حفظ دسته ‌بندی انتخاب ‌شده با پارامتر  cat و هدایت به بخش ‌های مختلف صفحه با استفاده از Fragment
- تنظیمات محیطی (.env): آدرس عمومی API برای محیط ‌های توسعه و ساخت Build


## ۴. قرارداد API
هنگام شروع برنامه، شش فایل با Promise.all دریافت می‌ شوند:
- اطلاعات کارت‌ های محصول: products.json
- دسته‌ ها، نام، slug، رنگ و ایموجی: categories.json 
- درصد و عنوان تخفیف محصول : offers.json
- زمان به‌ روزرسانی و موجودی :  stock.json
- اطلاعات فروشگاه، منو و فوتر: shop.json
- بنرها و فهرست کاروسل‌ ها: home.json

خروجی getJSON از نوع unknown است و پیش از استفاده بررسی می‌ شود.
محصولات نامعتبر حذف می‌ شوند و تعدادشان در Console گزارش می‌ شود.
## ۵. حالت‌ ها
- الف) loading : پیام "در حال بارگذاری فروشگاه..." نمایش داده می‌ شود.
- ب) success: بخش‌ های صفحه با داده‌ های بررسی‌شده ساخته می‌ شوند.
- ج) empty: در بخش محصولات پیام "کالایی پیدا نشد!" نمایش داده می ‌شود.
- د)  error: پیام درباره دریافت‌ نشدن اطلاعات نمایش داده می ‌شود.

نمایش حالت‌ ها با LoadState و switch انجام می‌ شود و default بررسی never دارد.
broken.json  و missing.json برای آزمایش حالت خطا استفاده می ‌شوند.


## ۶. پوشه‌ها
```text
src/
  types.ts
  api/
  storage/
  cart/
  catalog/
  ui/
  main.ts
```
- پوشه types.ts: نوع ‌های مشترک؛ بدون import.
- پوشه api/: دریافت JSON و بررسی داد ه‌های API با  Guardها
- پوشه storage/: خواندن و نوشتن سبد در localStorage.
- پوشه cart/  و catalog/:  سبد خرید، تخفیف، موجودی و فیلتر.
- پوشه ui/: ساخت و تغییر DOM با داده‌ هایی که دریافت می ‌کند.
- پوشه main.ts: نگهداری State، هماهنگی لایه‌ها، رویدادها و شروع برنامه.
