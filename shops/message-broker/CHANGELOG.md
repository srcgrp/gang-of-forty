# Changelog

## [1.0.0] - 2026-11-26

### Added
- Initial release of the Message Broker Shop.
- Added a responsive online fruit and vegetable storefront.
- Added API-driven shop information, banners, categories, products, offers, and stock data.
- Added product search, shopping cart, and notification features.
- Added TypeScript, Vite, and a modular application architecture.
- Added React components and state management with Zustand.
- Added persistent shopping cart storage using localStorage.
- Added theme management and multi-page routing with TanStack Router.
- Added Docker configuration.
- Added GitHub Actions CI/CD pipeline and Vercel deployment configuration.
- Added Playwright mobile screenshot.

### Changed
- Migrated the storefront from vanilla JavaScript to TypeScript and React.
- Refactored the application into reusable components and separate modules.
- Updated the production URL in shop.json.

### Fixed
- Fixed HTML validation and structure issues.
- Fixed TypeScript errors and application architecture issues.
- Fixed product search and poster image paths.
- Fixed shopping cart storage compatibility.
