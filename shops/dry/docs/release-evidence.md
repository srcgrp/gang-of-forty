# شواهد محلی انتشار MARTO

## CI و خطای عمدی

از یک کپی تمیز فروشگاه، `npm ci` و `npm run ci` موفق بودند. فایل آزمایشی با یک ناسازگاری نوع به یک کپی جداگانه اضافه شد. برنامه در گام `check` با خطای `TS2322` و کد خروج `1` متوقف شد. بعد از برداشتن فایل، اجرای همان دستور دوباره موفق شد.

در [PR آزمایشی CI](https://github.com/A-H-FEIZI/dry-shop/pull/2)، [اجرای قرمز](https://github.com/A-H-FEIZI/dry-shop/actions/runs/45639943606) با GitHub MCP بررسی شد. خطای `TS2322` در `src/release-check.ts:1` نشان داد مقدار `string` به متغیر `number` نسبت داده شده بود و `deploy` اجرا نشد. پس از جایگزینی مقدار با عدد، [اجرای سبز](https://github.com/A-H-FEIZI/dry-shop/actions/runs/45640346617) بررسی کد، Docker و Preview را پاس کرد.
