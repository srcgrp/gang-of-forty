# شواهد محلی انتشار MARTO

## CI و خطای عمدی

از یک کپی تمیز فروشگاه، `npm ci` و `npm run ci` موفق بودند. فایل آزمایشی با یک ناسازگاری نوع به یک کپی جداگانه اضافه شد. برنامه در گام `check` با خطای `TS2322` و کد خروج `1` متوقف شد. بعد از برداشتن فایل، اجرای همان دستور دوباره موفق شد.

برای بونوس اجرای قرمز روی GitHub، هنوز باید در مخزن مستقل یک PR آزمایشی ایجاد شود، لاگ job قرمز از طریق GitHub MCP خوانده شود و لینک اجراهای قرمز و سبز در PR تحویل قرار بگیرند.

## تمرین بازگشت نسخه

آزمایش در یک مخزن موقت انجام شد. یک متن اضافی انگلیسی در صفحهٔ اصلی نقش ایراد بصری را داشت. وجود آن در خروجی ساخته‌شده بررسی شد، سپس با `git revert` برگشت و در build نسخهٔ بعدی نبود.

| مرحله | کامیت آزمایشی | نتیجهٔ محلی |
| --- | --- | --- |
| 1.0.0 | `b06831d` | CI سبز. زمان اجرای اندازه‌گیری‌شده ۵۹٫۵ ثانیه. |
| 1.0.1 | `712081f` | CI سبز و ایراد در `dist/index.html` حاضر. زمان CI برابر ۴۳٫۵ ثانیه. |

برای امتیاز انتشار و بازگشت نسخه، زمان اجرای Production، زمان بازگشت و لینک سه اجرای واقعی باید بعد از انتشار در مخزن مستقل ثبت شوند. این زمان‌ها فقط مدت CI محلی‌اند.
